# Veo Documentary Editor — pure standard-library orchestration.
# No Python dependencies are required for the core pipeline.
#
# The only hard requirements are the FFmpeg binaries (ffmpeg + ffprobe),
# available on PATH (or configured via config.json: ffmpeg_bin/ffprobe_bin).
#   Debian/Ubuntu:  sudo apt-get install ffmpeg
#   macOS (brew):   brew install ffmpeg
#   Windows:        https://ffmpeg.org/download.html

# ---------------------------------------------------------------------------

# a GEMINI_API_KEY (free tier: https://aistudio.google.com/apikey).
# The core editor works fully without it (deterministic matching).
#
#   pip install google-genai
